# My Portfolio

Welcome to my portfolio! Below you will find a summary of my key projects across different areas such as Data Science, Web Development, Low-Level Programming (Assembly/C), and Hardware Description (VHDL).

---

### [Data Science] https://github.com/JoaoRozestraten/Data_Science
A collection of data science and machine learning projects focusing on data analysis and predictive modeling. It includes customer segmentation using K-Means, classification models with Random Forest and XGBoost, collaborative filtering recommendation systems, and a restaurant stay duration prediction API. Technologies used: **Python, Scikit-Learn, Pandas, XGBoost, and Matplotlib**.

### [Web Development Labs] https://github.com/JoaoRozestraten/Desenvolvimento-Web
A repository tracking the progression of web development skills through various laboratory exercises. It starts with fundamental HTML and CSS, moving towards backend development using **Node.js** and **Express**, including static page routing, file uploads, and EJS template rendering.

### [Data Structures in C] https://github.com/JoaoRozestraten/Estrutura-de-dados
A comprehensive collection of foundational data structures implemented from scratch in **C**. The project progresses from basic logic and dynamic memory allocation (`malloc`/`free`) to the construction and manipulation of Singly Linked Lists, Stacks (LIFO), and Queues (FIFO).

### [Monitoria Linguagem C] https://github.com/JoaoRozestraten/MonitoriaLinguagemC
A reference repository containing code developed during a teaching assistantship (monitoria) for a Computer Programming course at PUC Campinas. It serves as a guide for students learning fundamental programming logic and concepts in the **C language**.

### [Computer Systems Organization] https://github.com/JoaoRozestraten/Organizacao_de_sistemas_de_computacao
A series of practical exercises exploring low-level programming concepts, computer architecture, and memory management. The laboratory tasks are implemented in **x86 Assembly language** (16-bit DOS) and involve manipulating registers, data segments, and DOS interrupts.

### [Battleship in Assembly 8086] https://github.com/JoaoRozestraten/ProjetoBatalhaNavalAssembly
A fully playable, classic Battleship (Batalha Naval) game developed entirely in **8086 Assembly Language**. It features a terminal-based 20x20 grid, randomized ship configurations using the system clock, and an interactive gameplay loop for targeting coordinates.

### [Object-Oriented Tower Defense] https://github.com/JoaoRozestraten/ProjetoPOO
A 2D Tower Defense game built using **Java 17** and **JavaFX**. This project practically applies core Object-Oriented Programming (OOP) concepts—such as inheritance, polymorphism, and encapsulation—to manage different types of defensive towers, enemies, and player resources.

### [VHDL Projects & Labs] https://github.com/JoaoRozestraten/VHDL
A hardware description repository containing **VHDL** code, lab assignments, and testbench simulations. It encompasses fundamental components like multiplexers, decoders, and adders, serving as a structured codebase for hardware design and synthesis.

### [Integrative Health App] https://github.com/JoaoRozestraten/ProjetoIntegrador
A full-stack web application developed to help users track and manage health-related goals like weight and water consumption. It features a secure **Node.js/Express** backend with user authentication and dynamic frontend forms.
